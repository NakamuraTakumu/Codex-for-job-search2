共通レビュー契約:

成果物の正本は `${SUBCWD}` 内の指定された collected JSON file です。最終応答は完了通知であり、成果物としてレビューしないでください。

確認項目:

* 成果物が、job request の対象と、このレビューに共有された契約、対象 schema / model の `description`、`x-do_not` に従っているか。
* このレビューは、記録された値が `source` に支えられているかを確かめる唯一の工程である。時間やトークンを節約せず、判定を返す前に成果物に出てくる URL をすべて開き、その `source` が記録された値を直接支えているか確認する。再レビューでは、変更された値の URL を開き直す。開いて確認できない URL の `source` を根拠に `value` を妥当とみなさない。
* Missing の項目について、調査が十分だったかは判定しない。
* `note` の書き方や詳しさは判定しない。`note` が値や source と矛盾している場合だけ指摘する。

指摘:

* 問題があれば、`${SUBCWD}` 内の collected JSON file をどう直すべきかを指摘として返す。
