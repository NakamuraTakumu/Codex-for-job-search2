改訂モード:

* 既存の結果が入力に示されている。それを出発点にし、collected output path にコピーしてから、現行 schema に合わせて編集する。ゼロから作り直さない。
* 既存の結果は古い schema 版の形式かもしれない。その場合は現行 schema へ変換する（例：業種コードの単一値は 1 要素のリストにする、特定日の日付は earliest と latest が同じ DateRange にする）。変換では source と根拠を保持し、変換のために値や source を捨てない。
* 形式だけでなく、既存の records の source の kind なども現行 schema の description に照らして見直し、合わない場合は直す。
* コピーしたままでは現行 schema の検証を通らない場合がある。最終成果物は必ず現行 schema の検証を通す。
* Missing の項目や、不足している records・応募枠を調べて加筆する。
* 既存の値は、source で支えられていない、または誤っていると確認できた場合だけ修正または削除し、その理由を `note` に書く。
* 確認できなかったことを理由に既存の値を消さない。
* 最終成果物は schema 全体を満たす単一 JSON とする。
